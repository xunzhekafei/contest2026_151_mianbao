## 3. 演示段分镜

### 0:40–0:52 开机与联网

- 特写开发板、外壳、按键和接口；
- 展示开机画面；
- 屏幕出现岗位和“按 K1 开始面试”；
- 不要拍入手机号、Wi-Fi 密码和账号 token。

### 0:52–1:15 第一轮录音

- 手指按 K1；
- 特写 LED1 录音状态；
- 说一段 15–25 秒、信息量足够的自我介绍；
- 保留原声，不要整段配乐盖住按键和提示音。

### 1:15–1:40 云端追问与播放

- 拍板端播放状态和 LED2；
- 切网页录屏，展示同一条回答和面试官追问；
- 字幕标出“录音 → ASR → LLM → TTS”。

### 1:40–2:05 第二轮与报告

- 再完成一轮简短追问；
- 达到演示轮数后展示报告轮；
- 保留报告开头几秒原声，证明是整段播放；
- 不要求现场完整听完所有报告。

### 2:05–2:20 网页结果

- `/history` 展示本场会话；
- 展示总分、四维评分、逐题复盘；
- 快速展示 PDF/Markdown 导出入口。

## 4. 拍摄规范

- 横屏 16:9，1080p，30 或 60 fps；
- 手机或相机固定在三脚架，避免手持晃动；
- 出镜人物面向光源，背景干净；
- 使用领夹麦或靠近手机录音，避免空调和键盘噪声；
- 屏幕录制使用 1080p，浏览器缩放 100%；
- 每个镜头至少多拍 3 秒，方便剪辑留 handle；
- 文件名统一为 `YYYYMMDD_场景_序号.mp4`；
- 原始素材单独备份，不直接覆盖。

## 6. 补拍执行清单

### 全员镜头 A（0:05–0:40）

1. 四人并排站或围坐在设备后方，镜头横屏，人物胸口以上入画；
2. 先拍一张全员看镜头的封面帧，再连续录 3 遍；
3. 按刘宇童、陈希、杨灿、朱慧婷顺序各说一句，每句控制在 7～10 秒；
4. 中间不要停机，留 1 秒自然停顿，后期再切；
5. 至少一条里让开发板也入画，证明人和设备在同一现场。

### 全员镜头 B（2:20–2:50）

1. 四人仍保持同一机位，避免前后色调和构图跳变；
2. 依次说“还差什么 / 下一阶段怎么做”，不要照着稿子低头念；
3. 杨灿最后一句要明确说出“三轮实测、断网补送、报告轮验证”；
4. 说完后保持 3 秒不动，方便剪辑收尾。
